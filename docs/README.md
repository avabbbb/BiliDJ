## Authority

For current implementation decisions:

1. Explicit user instruction in the active task.
2. `AGENTS.md`.
3. Current documents in this directory.
4. Current source code.
5. Files under `docs/history/`.

A historical file is evidence of what BiliDJ used to be, not a requirement for what it should become.
